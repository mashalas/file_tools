# bkp.sh

Shell-скрипт создания резервных копий с добавлением текущей даты к имени архива.

Скрипту как параметр передаётся имя каталога или файла, для которых надо создать резервную копию.

Будет создан архив имя которого формируется путём добавления текущей даты в формате YYYY-MM-DD отделяемой двойным подчёркиванием от имени исходного объекта файловй системы.

Если файл с таким именем уже существует, то поcле даты добавляется буквенный индекс от "a" до "z". Если использованы все буквы английского алфавита, то добавлятеся числовой суффикс отделяемый от даты символом тильды (~).

Примеры имён архивов с резервными копиями:
```
documents__2026-10-11.zip - первая копия каталога documents созданная 11 октября
documents__2026-10-11a.zip - копия №2
documents__2026-10-11b.zip - копия №3
...
documents__2026-10-11z.zip - копия №27
documents__2026-10-11~1.zip - копия №28
documents__2026-10-11~2.zip - копия №29
...
documents__2026-10-11~12.zip - тридцатьдевятая копия каталога documents созданная 11 октября
```


### Поддерживаемые форматы ###
В настоящее время поддерживаются форматы:
 * zip
 * tgz
 * 7z

Пока формат задаётся внутри скрипта в переменной format:
```
export format=zip
```
